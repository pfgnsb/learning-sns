# 用語定義書

| 項目 | 内容 |
|---|---|
| 文書名 | 用語定義書 |
| 対象システム | 学習用SNS（X風のタイムラインアプリ） |
| 作成日 | 2026年10月30日 |
| 作成者 | nsb |
| 目的 | 本システムで使う言葉の意味を揃え、以後の資料と画面で同じ呼び方を使うため |

この資料は、アプリを作る前に決めておく「言葉の辞書」です。同じものを人によって違う名前で呼ばないようにします。

---

## 2. 似ている言葉の使い分け

| 使わない呼び方 | 本資料での呼び方 | 理由 |
|---|---|---|
| ツイート、リツイート、リポスト | 投稿。再共有の機能は無い | 本システムに再共有は無い |
| インプレッション、表示回数 | （使わない） | 見られた回数は保存も表示もしない |
| 返信、スレッド | コメント | コメントは投稿に対する1段階だけ |
| フォロワー申請、友達 | フォロー | 片方向で、承認は要らない |
| 相互フォロー | （特別な用語にしない） | 向きの違うフォローが2件ある状態。画面の特別表示はしない |
| おすすめ | （使わない） | 並びは新しい順だけ。おすすめ順は無い |
| セッション | JWT | ログイン状態はサーバセッションではなく JWT で表す |
| ハッシュタグ、投稿検索 | ユーザー検索 | 探す対象はユーザーだけ |
