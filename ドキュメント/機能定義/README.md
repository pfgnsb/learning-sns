# 機能定義

機能ごとの約束です。番号の一覧は [機能要件.md](../機能要件.md)、全体の範囲は [要件定義書.md](../要件定義書.md) を正とします。

一つずつ分けている理由は、登録、投稿、タイムライン、コメント、いいね、フォローが、それぞれ画面とデータの規則を持つためです。

| 資料 | 機能No. | 内容 |
|---|---|---|
| [アカウント.md](./アカウント.md) | A-1〜A-4 | 登録、JWT ログイン、ログアウト、アイコンと自己紹介 |
| [投稿.md](./投稿.md) | P-1〜P-3 | 本文と任意画像1枚。自分の投稿の編集と削除 |
| [タイムライン.md](./タイムライン.md) | T-1〜T-3 | 全体タブ、フォロー中タブ、投稿詳細 |
| [コメント.md](./コメント.md) | C-1〜C-2 | 投稿への1段階のコメント |
| [いいね.md](./いいね.md) | L-1〜L-3 | 投稿へのいいねと件数 |
| [フォロー.md](./フォロー.md) | F-1〜F-7 | ユーザー検索、フォロー、一覧、プロフィール |

各資料の構成は次で揃えます。

1. 目的と範囲
2. 規則
3. 操作フロー
4. 例外
5. 完成とみなす条件
