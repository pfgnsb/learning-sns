## 1. 読み方

| 記号 | 意味 |
|---|---|
| A | アカウント |
| P | 投稿 |
| T | タイムライン |
| C | コメント |
| L | いいね |

| 必須 | 空のままでは保存できない |

## 2. アカウント

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| A-1 | ユーザー登録する | 表示名、ユーザー名、メールアドレス、パスワードで作る。アイコンと自己紹介は任意。成功すると JWT を受け取り、全体タブへ進む | SCR-02 |
| A-2 | ログインする | ユーザー名またはメールアドレスと、パスワードで入る。成功すると JWT を返す | SCR-01 |
| A-3 | ログアウトする | 画面の JWT を捨て、ログイン画面へ戻る | SCR-03〜SCR-08 の共通ヘッダー |
| A-4 | アイコンと自己紹介を保存する | 自分のプロフィールだけ。アイコンは任意の1枚。自己紹介は空でもよく160文字まで | SCR-06 |

定義の正は [機能定義/アカウント.md](./機能定義/アカウント.md) です。

---

## 3. 投稿

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| P-1 | 投稿を作成する | 本文は1〜280文字で必須。画像は任意で1枚。JPEG、PNG、WebP。5MB以下。ファイルは S3 に置く | SCR-03 |
| P-2 | 投稿を編集する | 自分の投稿だけ。本文を直す。画像は維持、差し替え、削除のいずれか | SCR-03、SCR-04、SCR-06 |
| P-3 | 投稿を削除する | 自分の投稿だけ。確認のあと、コメント、いいね、S3 の画像も消す | SCR-03、SCR-04、SCR-06 |

定義の正は [機能定義/投稿.md](./機能定義/投稿.md) です。

---

## 4. タイムライン

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| T-1 | 全体タブを表示する | 全ユーザーの投稿を新しい順に出す。開いた直後はこのタブ | SCR-03 |
| T-2 | フォロー中タブを表示する | 自分の投稿と、フォロー中のユーザーの投稿を新しい順に出す | SCR-03 |
| T-3 | 投稿詳細を表示する | 投稿1件を出す。ログイン中なら、フォローしていない人の投稿でも開ける | SCR-04 |

定義の正は [機能定義/タイムライン.md](./機能定義/タイムライン.md) です。

## 5. コメント

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| C-1 | コメントを追加する | 投稿に対して1〜280文字の本文を追加する。画像は付けない。返信は作れない | SCR-04 |
| C-2 | コメント一覧を表示する | その投稿のコメントを古い順に出す。各コメントにアイコンを出す。0件のときは空であることを伝える | SCR-04 |

定義の正は [機能定義/コメント.md](./機能定義/コメント.md) です。

## 6. いいね

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| L-1 | いいねを追加する | まだいいねしていない投稿に1件付ける。ホームと詳細のどちらからでもできる | SCR-03、SCR-04 |
| L-2 | いいねを解除する | 自分のいいねだけを消す | SCR-03、SCR-04 |
| L-3 | 件数を表示する | いいね数とコメント数を出す。0も出す。行を数えた結果である | SCR-03、SCR-04、SCR-06 |

定義の正は [機能定義/いいね.md](./機能定義/いいね.md) です。

## 7. フォローとユーザー検索

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| F-1 | ユーザーを検索する | ユーザー名と表示名の部分一致。最大20件。投稿本文は探さない | SCR-05 |
| F-2 | プロフィールを表示する | アイコン、表示名、ユーザー名、自己紹介、フォロー数、フォロワー数、その人の投稿を新しい順に出す | SCR-06 |
| F-3 | フォローする | 承認なしの片方向。自分自身は不可。1人につき相手1人へ1件 | SCR-05、SCR-06、SCR-07、SCR-08 |
| F-4 | フォローを解除する | 自分のフォローだけを消す。相手の投稿はフォロー中タブから外れる。全体タブには残る | SCR-05、SCR-06、SCR-07、SCR-08 |
| F-5 | フォロー中一覧を表示する | そのユーザーがフォローしている人を、関係が新しい順に出す | SCR-07 |
| F-6 | フォロワー一覧を表示する | そのユーザーをフォローしている人を、関係が新しい順に出す | SCR-08 |
| F-7 | フォロー数とフォロワー数を表示する | プロフィールに出す。行を数えた結果である | SCR-06 |

定義の正は [機能定義/フォロー.md](./機能定義/フォロー.md) です。

## 8. 項目

| 項目 | 必須 / 任意 | 内容 | 対応する機能 |
|---|---|---|---|
| 表示名 | 必須 | 1〜50文字。重複可 | A-1 |
| ユーザー名 | 必須 | 4〜15文字。半角英字で始まり、続きは半角英数字または `_`。一意（大文字小文字は区別しない） | A-1、F-1 |
| メールアドレス | 必須 | 一意。メールアドレスの形 | A-1、A-2 |
| パスワード | 必須 | 8文字以上。ハッシュで保存する | A-1、A-2 |
| 投稿の本文 | 必須 | 1〜280文字 | P-1 |
| 投稿の画像 | 任意 | 0枚または1枚。JPEG / PNG / WebP。5MB以下 | P-1 |
| コメントの本文 | 必須 | 1〜280文字 | C-1 |
| 検索語 | 必須 | 前後の空白を除いて1〜50文字 | F-1 |
| 自己紹介 | 任意 | 空でもよい。160文字以下 | A-1、A-4 |
| アイコン | 任意 | 0枚または1枚。JPEG / PNG / WebP。5MB以下 | A-1、A-4 |

## 9. 例外（機能に関するもの）

| 状況 | 扱い | 関係する機能 |
|---|---|---|
| ユーザー名またはメールが重複 | 登録しない。重複した方を伝える | A-1 |
| ログイン情報が一致しない | ログインしない。失敗であることだけを伝える | A-2 |
| 本文が空、または281文字以上 | 保存しない | P-1、C-1 |
| 画像の形式または大きさが範囲外 | 投稿しない | P-1 |
| 同じ投稿へ2件目のいいね | 作らない | L-1 |
| 自分自身をフォローする | 作らない | F-3 |
| 同じ相手へ2件目のフォロー | 作らない | F-3 |
| 検索語が空白だけ、または51文字以上 | 検索しない | F-1 |
| ヒットが20件を超える | 20件と、絞り込みの案内を出す | F-1 |
| 未ログイン | ログイン画面へ送る | A-3 以外のログイン後機能 |
| 投稿が無い | 見つからない旨を出す | T-3 |
| 他人の投稿を編集または削除する | 受け付けない | P-2、P-3 |
| JWT が無い、または期限切れ | ログイン画面へ送る | A-2 以外のログイン後機能 |
| 自己紹介が161文字以上 | 保存しない | A-4 |
| API に繋がらない | 接続を確認する旨を出す | すべて |
